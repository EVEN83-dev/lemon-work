左栏 · 运行面板
brief（目标）/ sources（数据源）/ constraints（约束）/ budget（预算）/ prior_runs（历史）。回答“公司现在在什么条件下干活”。
中栏 · 3×5 工位
每个员工一张卡：状态灯、当前任务、tokens、runs、完成/失败、白名单数。回答“谁在干什么”。
中间竖条 · 脊柱
Agent 与任务/文件之间的依赖边，运行时流动，完成后收敛。回答“谁依赖谁”。
右栏 · 产出
units / agents / rejected / rules / broken，以及最新产物。回答“这轮产出了什么”。
底栏 · 三块
RUN LOG（谁在何时做了什么）/ DISPATCH（每个席位跑到哪）/ OUTPUT（最终产出与模拟权益）。
