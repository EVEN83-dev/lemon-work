一、系统架构图 SYSTEM ARCHITECTURE

Lemon Work 采用「本地优先、事件驱动、全链白盒」的五层架构。用户输入与 Agent 产出全部经过统一事件流（Trace）渲染，数字银行沙箱通过 UI 状态总线与 Agent 双向联动。

图 1 · Lemon Work 五层系统架构 —— 每一层均可独立审计，Agent 全部行为经 Trace 事件流白盒呈现

1.1 关键设计决策

决策说明收益
零侵入注入界面为 HTML/CSS/JS，由 Python 侧以 runJavaScript + QTimer 注入渲染器，不改 WebEngine 内核升级不影响宿主；渲染层可独立测试
统一事件契约Agent 全部行为收敛为 13 类 Trace 事件（见 2.3），前端只认事件不认引擎换引擎零改动；白盒完整可回放
多引擎热调度HealthMonitor 周期探测 DeepSeek / Ollama / 自定义引擎，主引擎失联自动降级切换断网可用（Ollama 本地兜底）
沙箱隔离数字银行为独立进程独立端口，仅绑定 127.0.0.1 回环，虚拟资金无真实支付通道Agent 可放手操作，零真实资金风险

二、核心算法说明 CORE ALGORITHMS

Agent 内核为「预算约束下的 ReAct 循环」：任务先经分类器定级获得轮数预算，循环中每一步工具调用都经 JSON Schema 强校验，全过程以事件流对外广播。

图 2 · Agent 核心算法：预算约束 ReAct 循环 + 语义任务拆解 + 全链事件流 + 页面跟随

2.1 任务分类器（轮数预算）

输入任务先按关键词与语义特征加权打分，划入三档，获得递归工具调用轮数上限。金融多步动词（推荐/办理/联动/切换/汇总等）强制进入 moderate 以上，防止多步业务被低预算截断。

等级判定特征轮数预算典型任务
simple单一查询意图、无多步动词≤ 6查余额、查产品列表
moderate多步金融动词 / 对比 / 推荐≤ 12理财推荐+申购、账单分析
complex跨场景联动、生成类综合任务≤ 20订花下单+页面联动展示

2.2 多引擎调度

EngineManager 维护引擎注册表，HealthMonitor 周期探测各引擎 /health。主引擎（DeepSeek）失联时自动降级到可用引擎并在界面提示；用户亦可在「模型中心」手动指定，或添加自定义 OpenAI 兼容端点（表单含连接测试、本地模型探测器只显示可连通项）。

2.3 白盒事件契约（节选）

事件语义渲染表现
run_start / run_end一次任务运行的开 / 收过程头状态灯 live→done、统计收口
thinking思考增量文本思考链分节点（段落切分、独立折叠、流式仅重绘活跃节点）
round工具轮开始（含 max_rounds）轮容器 + 预算徽标
tool_start / tool_end技能调用开始 / 结果工具条目，同名 ≥3 自动聚合
narrative轮内聚合播报过程时间线（"已查收款人 → 转账成功 → 预约定时转账"）
final结构化结论markdown 双保险渲染，超长自动折叠
meta用量统计usage-card：token / 轮数 / 工具数 / 耗时 / 上下文

3.1 四类安全边界

🌐 网络边界

银行沙箱与 UI 总线仅绑定 127.0.0.1 回环；系统对外仅有 LLM API 的出站 HTTPS；无遥测、无统计上报。

💰 资金边界

数字银行沙箱为纯虚拟账务，不接入任何真实支付 / 清算通道；风控引擎内置单笔限额、日累计、高频保护、收款方黑名单四规则。

📁 数据边界

对话、轨迹、配置全部存本机用户目录，可随时删除；发布包强制剔除 .git / 日志 / 用户数据并做复制完整性校验。

🔑 密钥边界

API Key 仅存本机配置；源码仓库与发布包均不含任何密钥（发布前专项审计确认）；风险与加密改进计划见《安全自评报告》R-01。

四、部署说明 DEPLOYMENT

提供「绿色免安装包」与「源码部署」两种方式，仓库与发布物均已开放。

方式 A · 绿色包（推荐评委体验）

1
从 Release 下载 LemonWork-v1.0.0-win64-portable.zip（371 MB，含内置 Python 运行时）
2
解压任意目录，双击 启动LemonWork.bat（银行沙箱随主程序自动拉起）
3
设置页填入 DeepSeek API Key（或选择 Ollama 本地引擎离线使用），即可对话体验六大场景
六大场景一键演示：演示六大场景.bat 自动依序执行 S1~S6，每场景停留 12 秒，便于评审观摩。

方式 B · 源码部署

1
git clone https://github.com/EVEN83-dev/lemon-work.git
2
pip install -r requirements.txt（核心：PyQt5 / PyQtWebEngine / requests / markdown）
3
python yh_main.py 启动；数字银行沙箱亦可独立运行：python server.py
4
测试回归：scripts\ 下四层测试脚本（白盒 / 巡航 / 端到端 / 六场景合规）
